  2. API キーを作成: 画面内の「Create API key（APIキーを作成）」または「Get API key」ボタンをクリックします。
  3. プロジェクトを選択: 「Create API key in new project（新しいプロジェクトでAPIキーを作成）」を選択すると、数秒でキーが生成されます。
  4. キーをコピーして早耳に保存: 表示された AIzaSy... から始まるキー文字列をコピーし、上の入力欄に貼り付けて「保存する」ボタンを押してください。
