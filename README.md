# Hayamimi Live

Hayamimi Live（早耳 Live）は、ローカルで動作するリアルタイム音声認識・多言語翻訳字幕ツールです。CPU、NPU（実験的）、GPU（実験的）の推論モードを選べます。

標準の CPU モードは GPU を使わず、一般的な PC で軽量・低遅延に推論処理を行います。OBS Studio などの配信ソフトに透過字幕として重ねて表示できます。

このプロジェクトは、オリジナルのFork元Hayamimiに主に自分用にAIの支援を受けてガワを付けたものです。

## 概要

本ツールは、配信者や動画制作者が手軽にリアルタイム字幕および多言語翻訳字幕を導入できるように設計されています。

ライブ中の音声処理と翻訳処理はすべてローカルマシン内で完結するため、外部サービスへの通信や利用料の発生を気にせず利用できます。  
※YouTube アーカイブから話者プロファイルを生成する場合のみ、YouTube からの動画取得と、Google AI Studio (Gemini API) への音声送信が発生します（API キーはローカルに保存されます）。

### 主な特徴

- **CPU 単体での低遅延推論**:
  INT8 量子化された ONNX モデル（日本語は CPU・NPU モードで Haas-Ja、英語・多言語は各言語の専用モデル）を採用し、発話終了後おおむね 100〜200msでテキストを確定します。
- **選べる推論モード**:
  CPU（標準）、NPU（Intel・実験的）、GPU（NVIDIA・実験的）をランチャーで切り替えられます。GPU モードでは Whisper を使い、話者特化 LoRA を学習できます。
- **リアルタイム多言語翻訳**:
  発話された日本語から、英語（FuguMT CTranslate2）や中国語、韓国語、欧州言語（M2M-100）への翻訳文を並行して出力します。
- **柔軟な字幕スタイリング**:
  Web 設定画面から、フォント、文字サイズ、文字色、外枠（縁取り）、表示エフェクト（通常枠、二重枠、グロー発光）をリアルタイムに調整可能です。発話テキストと翻訳テキストで異なるスタイルを個別に割り当てることもできます。
- **YouTube アーカイブからの辞書自動生成（話者特化プロファイル）**:
  過去の配信動画、再生リスト、またはチャンネルの URL を指定することで、自身の発話特性やゲーム内用語・固有名詞を解析し、誤認識を防ぐ置換辞書を自動生成できます。
- **配信タイトル連動の優先タグ（Priority Tags）**:
  動画タイトルおよび説明文（概要欄）内のハッシュタグ（例: `#ApexLegends`, `#ストグラ`）を用語ごとに自動付与。Webマイク画面 (`/mic`) から配信ゲームに合わせてタグを複数選択でき、該当する固有名詞辞書をに即座に自動投入できます。
- **コメント連動の補正**:
  配信コメントに出た語や視聴者の名前を配信者が話したとき、音の近い誤認識をそこだけ直します（既定はオフ）。
- **形態素解析エンジン（SudachiPy）による補正**:
  ゲーム特有の造語や略称の誤分断を防ぎ、リアルタイム認識の途中表示および確定表示の双方で高速かつ自然な単語境界補正を行います。
- **プライバシー**:
  ライブ中のマイク音声と文字起こしは PC 内で処理し、外部へ送信しません。プロファイル生成では、対象動画の音声を Gemini API（Google）へ送信します。無料枠のキーでは送信内容が Google のサービス改善に使われ、担当者が確認する場合があります。詳しくは [MANUAL.md](MANUAL.md#7-話者特化プロファイル機能辞書置換設定) をご覧ください。

## 基本的な使い方

### 1. 起動
フォルダ内の `start.bat` を実行します。  
ランチャー画面が表示されたら、実行基盤と推論モードを選び、「アプリ起動 & Webを開く」をクリックします。

### 2. OBS Studio への追加
1. OBS Studio の「ソース」パネルで「+」を押し、「ブラウザ」を追加します。
2. URL に `http://localhost:8833/`、幅 `1920`、高さ `1080` を指定します。
3. プレビュー画面上に透過字幕が配置されます。

### 3. 音声入力とデザイン調整
ブラウザで `http://localhost:8833/mic` を開きます。  
マイク入力の有効化、翻訳先言語の選択、字幕フォントや配色の調整を画面上で行えます。変更内容は OBS 側の字幕表示へ即座に反映されます。

### 4. 辞書自動生成 & 優先タグ選択（必要に応じて）
ブラウザで `http://localhost:8833/profile` を開き、自身の YouTube 配信アーカイブの URL を入力すると、タイトル内のハッシュタグ（`#Apex` 等）を自動判別し、ゲーム固有名詞や認識の癖を学習したカスタム辞書を作成できます。作成されたプロファイルは、Web マイク画面 (`/mic`) の話者プロファイル設定から優先タグを複数選択（トグル）してワンクリックで ASR に適用できます。再読み込みボタンも備えており、プロファイル作成後すぐに反映可能です。
