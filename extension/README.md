# 早耳 OBS 連動拡張機能 (Hayamimi OBS Sync)

早耳 (Hayamimi Live) クラウド版と手元 PC の **OBS Studio (OBS WebSocket v5)** を完全自動で連携させる Chrome 拡張機能です。

ブラウザのセキュリティ制約（HTTPS Mixed Content）を安全に回避し、OBS 側でマイクがミュートされた瞬間に早耳のリアルタイム文字起こしを自動休止します。

---

## 🛠️ インストール手順 (約 30 秒)

本拡張機能は、Chrome の「デベロッパーモード」を使って 1 回読み込むだけで即座に使用できます。

1. **Chrome で拡張機能の管理画面を開く**:
   - アドレスバーに `chrome://extensions` と入力して Enter を押します。
   - （または、Chrome 右上のメニュー「︙」→「拡張機能」→「拡張機能を管理」を開きます）。
2. **デベロッパーモードを ON にする**:
   - 画面右上にある **「デベロッパーモード」** のトグルスイッチを **ON** にします。
3. **拡張機能フォルダを読み込む**:
   - 画面左上に現れる **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。
   - 本リポジトリの **`extension` フォルダ** を選択します。
4. **準備完了！**:
   - 早耳マイク画面（`https://hayamimi.kit-a.net`）を開くと、自動的に拡張機能が検出され、OBS との連動が有効になります！

---

## ⚙️ OBS Studio 側の設定確認 (OBS 28 以降標準搭載)

1. OBS Studio を開き、上部メニューの **[ツール] → [WebSocket サーバー設定]** を開きます。
2. **「WebSocket サーバーを有効にする」** にチェックが入っていることを確認します（ポート番号: `4455`）。
3. ※認証（パスワード）を有効にしている場合は、早耳マイク画面の OBS 設定詳細にパスワードを入力してください。

---

## 🔒 セキュリティについて
- 本拡張機能はローカルの `ws://127.0.0.1:4455` (OBS WebSocket) と早耳ドメインとの間でのみ通信します。
- 外部への個人情報や音声データの送信は一切行いません。
